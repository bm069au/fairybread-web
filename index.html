📖 Fairybread User Guide & Operating Instructions

This is the complete operating manual—also built directly into the desktop app (press F1 or click Help → 📖 User Guide anytime).

⬇ Download Fairybread Beta

1. Quick Start: Connecting Your API Keys in 60 Seconds

1. Launch Fairybread and click ⚙ Settings & AIs (bottom-left) or Settings → Fairybread Settings….
2. Select any provider in the AI Providers tab (e.g., Gemini, OpenAI, DeepSeek, Groq, Qwen, Cohere, Mistral, Cerebras, or Ollama).
3. Need an API key? Click the built-in 🔑 Get API Key ↗ button to open that provider's exact API key page in your browser.
4. Paste your key, tick Enable this AI provider, and click ↻ Fetch Live Models to load the newest models automatically. Your key is encrypted locally on your PC using Windows DPAPI.

2. Toolbar Controls, Council Deliberation & Live Voice Mode

• Choose AIs ▾: Toggle which AI providers are active or pick a preset Squad.
• Council (Purple when ON): Runs 2-Round Peer Deliberation (agents answer in Round 1, critique and cross-examine each other in Round 2, and synthesize one best answer). Turn OFF for fast 1-round synthesis.
• Tangent: Ask a quick side question without including prior conversation history.
• {} Code: Grants read-only visibility into Fairybread's own source code.
• 🎤 (Dictate) & |||✨ (Hands-Free Live Voice Mode): Click 🎤 to dictate speech into the text box, or click |||✨ for continuous hands-free voice chat with a live soundwave volume meter (🎙 ▂▅▇█▄▂) and spoken responses!
• Memory (Top-Right): Open your 100% local SQLite FTS5 Shared Memory and click 📝 Memory Summary (View & Edit)… to view or edit what all connected AIs remember about you and your projects.

3. High-Resolution Image, Banner & 300-DPI Print Studio

• Default 1-Pass Drawing Mode: Just ask in plain English: "Draw a photorealistic ginger cat on a sunlit windowsill" or "Create a YouTube banner for a gaming channel".
• Council-Assisted Prompt Brainstorming: Ask "All agents work on the prompt and then only one of you execute the drawing: ..." so all active AIs collaborate on the visual prompt before rendering.
• Built-In Platform & Print Presets: Automatically sizes and stamps 300-DPI metadata for YouTube banners (2560×1440), YouTube thumbnails (1280×720), Facebook covers (1920×1080), 4K wallpapers (3840×2160), Phone stories (1080×1920), 8×10 in prints (2400×3000 @ 300 DPI), and A4 prints (2480×3508 @ 300 DPI).

4. Autonomous Experimental Mode Lab & Agent Mail

• Open the Mode → 🧪 Experimental Mode menu to launch the autonomous multi-agent lab (the top-right badge shows OFF, 🔴 RUNNING, or ⏸ STOPPED).
• In the Public Edition, agents converse in 💬 Free Talk, store durable notes in Shared Experimental Memory, and message you via Agent Mail.
• Why Live Code Self-Modification Is Disabled in Public Builds: Self-patching (/autopatch & [IDLE_PATCH]) is hardwired OFF in non-Developer builds so public installations remain verified, consistent, and cannot bypass licensing or safety restrictions. Have an improvement idea or proposed patch? Post it in the Fairybread Community Forum or email bm069au@gmail.com for review.
• Customize the session timer, token/USD spend caps, startup prompt, and ethics charter in Settings → Experimental Mode.

5. Custom Themes, System Tray & AES-256 Encrypted Backups

• Install Custom Skins: Download any .json skin from the Themes & Skins tab and click View → 🎨 Theme → 📥 Import Custom Theme (.json)….
• Close to System Tray: Clicking the window ✕ button minimizes Fairybread to the Windows System Tray so background tasks keep running safely (right-click the tray icon to Expand or Exit).
• Password-Locked Portable Backups: In Settings → Backup & Restore, export a single AES-256-GCM encrypted .zip backup containing all your memories, sessions, themes, and API keys to move to a new PC in one click.
